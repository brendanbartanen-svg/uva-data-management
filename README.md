# EDLF 5310 rules for Claude Code

This repository holds one file, `CLAUDE.md`: the rules Claude Code follows in a student's project folder for EDLF 5310, Data Management for Quantitative Research (University of Virginia, Fall 2026).

Claude Code reads a file named `CLAUDE.md` in the project folder at the start of every session. The file says how data work is done in this course: every result comes from an R script the student can read, raw data is read-only, checks are shown, and decisions stay with the student.

## Put the rules in your project

Open Claude Code on your `edlf5310_project` folder and send:

> Download the file CLAUDE.md from this repository and save it as CLAUDE.md in this folder: https://raw.githubusercontent.com/brendanbartanen-svg/uva-data-management/main/CLAUDE.md

Then open `CLAUDE.md` and read it. It is a plain text file, and you can add rules of your own below the course rules.

## Get an updated version

When the rules change, send the same request again. If you added rules of your own, tell Claude to keep them.

## What the rules do not do

The rules are instructions. Claude usually follows them, and they do not block an action. Read each edit and each command before you approve it.
